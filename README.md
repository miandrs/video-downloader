# Video Downloader by miandrs

## Installation

1. Open a terminal, then clone the project:

   ```bash
   git clone https://github.com/miandrs/video-downloader.git
   ```

2. Navigate to the project directory:

   ```bash
   cd video-downloader
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```
4. Before Running the front application run the backend first:
   [Backend Repository](https://github.com/miandrs/video-downloader-backend.git)

4. Start the server:
   ```bash
   ng serve
   ```
